## 一、结论先行

**整个 `DeepSeekWatch/` 目录原样打包发送即可，一个文件都不要少。**

不需要做任何筛选。缺失任何一个文件都会导致工程无法打开或编译失败。
打包方拿到的是一个**完整的 DevEco Studio 工程**，直接 `Open` 就能用。

如果你只想确认"没有多余文件"——确实没有。下面逐一说明每个文件的作用。

## 三、打包方拿到后应该做什么

### 第 1 步：打开工程
```
DevEco Studio ≥ 5.0 → File > Open → 选择 DeepSeekWatch/ 目录
```
⚠️ 选**外层 `DeepSeekWatch/`**，不是 `entry/`。

### 第 2 步：检查三处配置（改不改都行，确认一下）

```
entry/src/main/module.json5        → deviceTypes 是否含 "wearable"
build-profile.json5                → compatibleSdkVersion（当前 5.0.0(12)）
AppScope/app.json5                 → bundleName: com.dswatch.round
```

**★ 最重要的一处改动：`compatibleSdkVersion` 必须提到 API 18。**

表冠用到的 `onDigitalCrown` / `CrownEvent` 是 **API 18 才引入、且仅 Wearable 支持**的接口。
当前工程里写的 `5.0.0(12)` 是保守值，若打包方在旧 SDK 上直接编译，`onDigitalCrown`
会报"属性不存在"。正确做法：

```json5
// build-profile.json5
"compatibleSdkVersion": "5.0.1(18)",   // 或与打包方本地 SDK 对齐的 ≥18 版本
"targetSdkVersion": "5.0.1(18)"
```

代码侧无需任何改动 —— `Crown.ets` 已把角度换算、反向抵消、步进阈值做成纯 TS 逻辑，
`onDigitalCrown` 只负责把 `CrownEvent.degree` 喂进来。

### 第 3 步：签名 + 构建
```
File > Project Structure > Signing Configs → 勾选自动签名（需登录华为账号）
Build > Build Hap(s)/APP(s) > Build Hap(s)
```
产物：`entry/build/default/outputs/default/entry-default-signed.hap`

### 第 4 步：装到手表
```bash
hdc install entry-default-signed.hap
```

### 第 5 步：真机验证（3 项）
1. **登录** — 密码登录能否成功（沙箱没验成，因为境外 IP 被风控）
2. **PoW 耗时** — 发第一条消息时，状态条显示"准备中"要停留多久；> 5 秒需优化
3. **表冠** — 登录页转表冠能否切字号；对话页转表冠能否翻消息

## 四、明确不需要做的事

- ❌ **不要补验证码 UI**。密码登录不触发人机验证，这是实测结论，不是漏做。
- ❌ **不要改 `Sha3.ets` 的算法**。已通过 `SHA3-256("")` 和 `SHA3-256("abc")` 标准向量。
- ❌ **不要改成 `model_type: "expert"`**。官网 expert 模型已下线（disabled），改了会 400。
- ❌ **不要删 `hvigor/` 目录**。它看着像缓存，其实是构建必需。
- ❌ **不要把 `deviceTypes` 改成 `phone`**。改成 phone 会导致手表装不上。

## 五、如果要裁剪或改造

| 想做什么 | 动哪里 |
|---|---|
| 改应用名 | `AppScope/resources/base/element/string.json` |
| 改包名 | `AppScope/app.json5` → `bundleName` |
| 换图标 | 替换 `AppScope/resources/base/media/` 下 3 张 PNG |
| 调字号基准 | `common/RoundScreen.ets` → `Typo` 里的 `14 / 11 / 17 / 21` |
| 调表冠灵敏度 | `common/Crown.ets` → `STEP`（默认 18 度，越小越灵敏） |
| 调翻页步长 | `common/Crown.ets` → `ContextScroller.step`（默认 48px） |
| 加会话列表页 | 调 `/api/v0/chat_session/fetch_page`，见 `API_SPEC.md` |
| 换主题色 | 全局搜索 `#4D6BFE` |
